01 · researchedition 1 out

ARI-42, Agent Risk Index

An open index of the 42 security requirements a product built on AI agents should meet, with evidence-linked ratings of how far 85 widely used agent frameworks, SDKs, harnesses and MCP tools take a builder toward each one. Every requirement is tied to the 2025-26 CVE and incident record that motivates it, and cross-walked to OWASP, MITRE ATLAS, CoSAI and ISO.

85agent tools rated
2,099ratings, each with a source
129,058CVEs screened
759AI incidents reviewed
Finding: tools meet a requirement by default in 2% of cases.
02building

GLoop

One chat for every coding agent and loop on your machine. You talk to one router agent; it writes the loop prompt for the right project and only interrupts you when a decision is yours. gstack-loops v2.

03 · most usedused by developers

gstack-loops

A loop engineering kit built on gstack. Run as many feature loops in parallel as you want: each gets its own worktree, its own set of ports so parallel builds never collide, and its own QA run. A loop goes spec → build → review → QA → ship and keeps going until the tests pass, so it finishes the whole development cycle and hands you a PR.
